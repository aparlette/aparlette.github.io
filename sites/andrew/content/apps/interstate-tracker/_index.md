Interstate Tracker records which parts of the U.S. Interstate Highway System
you have driven, and maps what is left. An Android app records the drive — or
imports a GPX file — and matches the trace against real interstate geometry;
the web app renders your coverage back per route and per state.

The web app and the sync API are live. The Android app is not publicly
released.

  site, and the place to start

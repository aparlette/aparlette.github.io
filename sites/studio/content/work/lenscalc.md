## What it does

Five calculators a photographer actually reaches for, on a phone, in the
field or the night before a shoot:

- **Depth of field** — how much will be sharp, and where the near and far
  limits fall
- **Field of view** — what a given focal length will actually take in
- **Exposure** — how much filtration a long exposure needs
- **Crop factor** — equivalence across sensor sizes
- **Subject size in frame** — how large a thing of known size will appear,
  which is the calculation that decides whether you brought the right lens

It is aimed at APS-C shooters, and it is the one project where the two halves
of the studio meet.

## Where it stands

**Built, and not yet published.** All five calculators work. It has never
been deployed anywhere, so there is no link.

Publishing it is the obvious next move — it is a static page with no server
and no build step, so it can be hosted here as-is whenever it is worth doing.

## How it is built

Plain HTML, CSS, and vanilla JavaScript ES modules. No server, no build step,
no dependencies.
